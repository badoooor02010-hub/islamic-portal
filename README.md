# أبحاث ومشاريع الدراسات الإسلامية - المتوسطة الثانية

لوحة مشاريع تفاعلية (بأسلوب Padlet) لمشاريع وأبحاث الدراسات الإسلامية،
إشراف الأستاذة بدرية المالكي. مبنية بـ React + Vite + Tailwind CSS.

- **البيانات والدخول:** Firebase Firestore + Authentication
- **تخزين الملفات:** داخل Firestore نفسها كـ Base64 — بدون Storage وبدون
  Cloudinary وبدون أي إعداد فوترة (حد الملف ~700KB، والصور تُضغط تلقائياً)
- **مشروع Firebase:** `islamiceducation-5ec35` (مستقل تماماً عن مشروع
  التربية البدنية `projet-pe-65644`)

## الأقسام

| القسم | من ينشر؟ |
|------|----------|
| أول متوسط (التوحيد، التفسير، الحديث، الفقه) | الطالبات + المعلمة |
| استراتيجيات المعلمة | المعلمة فقط (بعد تسجيل الدخول) |
| استراتيجيات أنماط التعلم | المعلمة فقط (بعد تسجيل الدخول) |

دخول المعلمة مخفي — اضغطي على صورة المعلمة في الترويسة لفتح نافذة الدخول.

## التشغيل محلياً

```bash
npm install
npm run dev
```

يعمل الموقع فوراً في **وضع المعاينة** (تُحفظ البيانات في متصفحك) حتى بدون
إعدادات — مفيد لمعاينة التصميم والتجربة.

## الربط الفعلي — Firebase فقط

1. ملف `.env` يحتوي بالفعل إعدادات تطبيق الويب `islamic_education`
   (أو انسخي `.env.example` إلى `.env` واملئي قيم `VITE_FIREBASE_*`).
2. فعّلي الخدمات في وحدة التحكم لمشروع `islamiceducation-5ec35`:
   - **Authentication** → فعّلي Email/Password، ثم أضيفي حساب المعلمة
     (Users → Add user).
   - **Firestore Database** → أنشئي قاعدة البيانات.
3. انسخي محتوى `firestore.rules` إلى Firestore → Rules
   (أو انشريها عبر `firebase deploy --only firestore:rules`).
4. أعيدي تشغيل `npm run dev`.

> ملاحظة: لا حاجة لتفعيل Firebase Storage إطلاقاً — الملفات تُحفظ كنصوص
> Base64 داخل مستندات Firestore مباشرة.

### حدود الملفات

الحد الأقصى للملف الواحد **20MB**. نظراً لأن مستند Firestore محدود بـ 1MB،
تُحفظ الملفات بطريقتين:

- **حتى ~700KB:** تُخزن كنص Base64 داخل مستند المشاركة مباشرة.
- **أكبر من 700KB:** تُقسم تلقائياً إلى أجزاء (chunks) داخل مجموعة فرعية
  وتُعاد تجميعها عند العرض — تدعم الصور والفيديو وPDF وWord.
- **الصور:** تُضغط تلقائياً داخل المتصفح قبل الحفظ عند الحاجة.

## الصلاحيات

| الدور | المشاركات (أول متوسط) | استراتيجيات المعلمة | استراتيجيات أنماط التعلم |
|------|----------------------|---------------------|--------------------------|
| طالبة/زائرة | قراءة + إضافة فقط | قراءة فقط | قراءة فقط |
| المعلمة (مسجلة) | قراءة + تعديل + حذف | تحكم كامل | تحكم كامل |

## البناء للإنتاج والنشر

```bash
npm run build
firebase deploy --only hosting
```

الناتج في مجلد `dist/` — يُنشر على Firebase Hosting الخاص بمشروع
`islamiceducation-5ec35` (الخطة المجانية).
